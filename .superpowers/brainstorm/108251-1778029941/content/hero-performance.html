Performance & Interaction Strategy

How should the hero behave across devices?

A

Full Experience Everywhere

Same 3D portal + particles on all devices. Use Canvas/WebGL for GPU-accelerated rendering. Detect low-end devices and reduce particle count automatically. Risk: battery drain on older phones.

B

Tiered: Full Desktop, Light Mobile

Desktop gets the full 3D portal with mouse-reactive particles. Mobile gets a simplified version — CSS-only animated gradient vortex with fewer, lighter particles (no WebGL). Still looks great, but prioritizes battery and performance on phones.

C

CSS-First with Canvas Enhancement

Build the core vortex effect with pure CSS (gradients, transforms, animations). Layer a lightweight Canvas particle system on top that gracefully degrades. No WebGL dependency. Works everywhere, enhances where possible. Smallest bundle size.
